# elitebasket.al

Ky është një projekt statik për GitHub Pages. Aktivizoni **Settings > Pages > Source: GitHub Actions** në depo. Çdo `push` në degën `main` publikon përmbajtjen e dosjes `public`.

Skedari `public/CNAME` vendos domenin e personalizuar `elitebasket.al`. Konfiguroni DNS dhe verifikoni domenin në GitHub.

Për rrugët që nuk ekzistojnë, GitHub Pages shfaq `public/404.html` me status HTTP `404`.
